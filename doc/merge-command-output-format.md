# マージコマンドの出力フォーマット

## 目的

YAML形式の辞書データを、SKKを再実装したEmacs拡張で利用できるかな漢字変換辞書JSONに変換する。Issue #13 の要件に合わせ、読みをキー、変換候補の漢字を配列として表現する。

## 形式

- 文字コードはUTF-8とし、BOMは付けない。
- JSONのトップレベルはオブジェクトとする。
- プロパティ名は読みを表す文字列、値は候補の漢字を並べた文字列配列とする。
- 同じ読みを持つ辞書エントリーは、ひとつのプロパティにまとめる。
- JSONとして意味のないコメントや追加のメタデータは含めない。

```json
{
  "あい": [
    "愛",
    "藍"
  ],
  "あお": [
    "青",
    "蒼"
  ],
  "はし": [
    "橋",
    "箸"
  ]
}
```

## 出力の安定性

- 人が確認しやすいよう、インデント幅2の整形済みJSONを出力し、末尾に改行を付ける。
- 読みのキーは昇順で出力する。同じ入力から常に同じファイルを生成できるようにする。
- 同じ読みの候補は、入力された辞書データでの出現順を維持する。候補の重複除去や入力ファイル間の優先順位は、出力形式とは別にコマンド仕様で定義する。
- エントリーがない場合は空のオブジェクト `{}` を出力する。

## この形式を選ぶ理由

読みから候補配列を直接引けるため、変換側で辞書データを再構築せずに利用できる。JSONオブジェクトと文字列配列だけで構成することで、一般的なJSONパーサーで扱いやすく、同じ読みへの複数候補も自然に表現できる。
